# AGENT.md: معماری فنی، راهنمای مهندسی و مشخصات سیستم حسابداری تمام‌خودکار هلند (MoneyBirds NL)

> **خلاصه پروژه:**  
> ساب‌فولدر `frontend/` حاوی اپلیکیشن اصلی **MoneyBirds NL** است؛ یک سیستم تک‌صفحه‌ای (SPA) و وب‌اپلیکیشن پیشرونده (**PWA**) توسعه‌یافته با **React 18 + Vite + TypeScript + TailwindCSS + Supabase + TanStack Query**.  
> این پلتفرم با تحلیل دقیق و ادغام برترین قابلیت‌های دو پلتفرم مرجع هلند مهندسی شده است:  
> 1. **Moneybird.com:** پیشرو در فاکتورسازی تعاملی، سیستم آفرها و پیش‌فاکتور (Offerte)، مدیریت سقف ساعت کارآفرینان (Urencriterium) و پیگیری مطالبات قانونی (WIK).  
> 2. **Jortt.nl:** پیشرو در ربات حسابداری تمام‌خودکار (De Boekhoudbot)، اتصال لایو بانکی PSD2، ارسال مستقیم اظهارنامه به Digipoort بلستینگ‌دینست و ترازنامه سالانه KVK.  
> **نوآوری و تمایز کلیدی:** پشتیبانی بومی **۱۰۰٪ راست‌چین (Native RTL)** برای جامعه کارآفرینان و فریلنسرهای مهاجر در هلند با تایپوگرافی اختصاصی (`Vazirmatn` / `B Yekan`)، ایزولاسیون دوطرفه داده‌های مالی (Dutch IBAN, BTW-id, KVK)، معماری PWA و سیستم وب‌پوش نوتیفیکیشن.

## ۳. استانداردهای طراحی بومی ۱۰۰٪ راست‌چین (100% RTL Design System)

### ۳.۱. قوانین اکید کلاس‌های منطقی (CSS Logical Properties):
برای اینکه نرم‌افزار بدون مشکل بین زبان‌های فارسی/عربی و هلندی/انگلیسی جابجا شود:
1. **مارجین و پدینگ:**
   - منحصراً از `ms-*` (Margin Start) و `me-*` (Margin End) استفاده شود؛ از به کار بردن `ml-*` و `mr-*` خودداری فرمایید.
   - منحصراً از `ps-*` (Padding Start) و `pe-*` (Padding End) استفاده شود؛ از به کار بردن `pl-*` و `pr-*` خودداری فرمایید.
2. **پوزیشنینگ و چیدمان:**
   - به جای `left-*` و `right-*`، از `start-*` و `end-*` استفاده شود.
3. **تایپوگرافی چندزبانه:**
   - در حالت راست‌چین: فونت به صورت خودکار به `Vazirmatn`, `B Yekan`, `system-ui` تغییر می‌کند.
   - ارقام بانکی و شناسه‌ها: شماره شبا هلند (`NL..ABNA..`)، شناسه KVK و کد BTW-id باید درون تگ ایزوله `<bdi dir="ltr" class="font-mono">` قرار گیرند تا نظم متن حفظ شود.

## ۴. زیرساخت PWA و وب‌پوش نوتیفیکیشن (PWA & Push Notification Hub)

### ۴.۱. لیسنر دریافت اعلانات در `public/sw.js`:
سرویس‌ورکر پیاده‌سازی شده در برنامه قابلیت مدیریت ترافیک آفلاین و نمایش اعلانات سروری را داراست:
```javascript
// دریافت اعلان وب‌پوش و نمایش در نوار اعلانات سیستم‌عامل
self.addEventListener('push', (event) => {
  const data = event.data ? event.data.json() : {}
  self.registration.showNotification(data.title || 'MoneyBirds NL', {
    body: data.body,
    icon: '/favicon.svg',
    dir: 'rtl',
    lang: 'fa',
    data: { url: data.url || '/' }
  })
})
```

### ۴.۲. ماژول کلاینت `src/lib/pwaPush.ts`:
- توابع `registerServiceWorker()`، `subscribeToPushNotifications(vapidKey)` و `getPushSubscriptionState()` آماده اتصال به دیتابیس هستند.

## ۵. هسته ربات حسابداری تمام‌خودکار (De Boekhoudbot Core)

الگوی تطبیق هوشمند یورت در فایل‌های `BankReconciliation.tsx` و الگوریتم‌های آینده به صورت زیر توسعه می‌یابد:
1. **تطبیق فازی ۹۹٪ (Fuzzy Matching):** مطابقت دادن همزمان شماره فاکتور (مثال: `2026-042`) و نام مشتری در توضیحات تراکنش بانکی.
2. **تولید هزینه از تراکنش (Cost from Transaction):** در صورت تراکنش خروجی (Debit)، ایجاد فوری سند هزینه با کسر اتوماتیک مالیات ۲۱٪ یا ۹٪.
3. **پایش سقف‌های مالیاتی:** اتصال به اظهارنامه مالیاتی فصلی برای محاسبه خودکار مانده قابل پرداخت یا استرداد (Rubriek 5g).

## ۶. پروتکل‌های عملیاتی برای دستورات `/goal`

هنگامی که کاربری دستوری را از طریق **`/goal`** اجرا می‌کند، عامل هوشمند باید:
1. **تست بیلد الزامی:** بلافاصله پس از تغییرات، دستور `npm run build` را در پوشه `frontend/` اجرا کرده و از خروج با کد صفر اطمینان حاصل کند.
2. **عدم بازگشت کانتینرهای باریک:** حفظ ساختار `w-full max-w-[1800px] mx-auto` در تمام صفحات جدید.
3. **پایداری سشن کاربر:** احراز هویت با استفاده از هوک `useAuth()` در تمامی مسیرهای جدید.
4. **رعایت RTL:** استفاده انحصاری از کلاس‌های منطقی تیل‌ویند.
